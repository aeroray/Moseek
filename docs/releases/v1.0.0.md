# v1.0.0

第一个正式版本。

## 本次包含

- **影视库**：聚合检索、分类浏览、多线路播放。列表只发一次请求，源没提供封面就显示「暂无海报」，不会为封面额外发请求。
- **电视直播**：HLS 与 HTTP-FLV 播放，频道分组、搜索、线路探测与 EPG 节目单。
- **配置中心**：TVBox / CatVod 配置导入（含图片内嵌配置、多仓地址选择），导入前先列出全部条目由你勾选；导入即合并去重；源可单独启用、测速、删除。
- **我的收藏 / 足迹**：影视与电视直播分开记录，收藏可续播。
- **系统设置**：主题、播放器、安全与网络、存储、关于与更新。
- **自动更新**：从 GitHub Releases 检查新版本，安装包会校验签名后才安装。

## v0.1.0 以来的主要变化

- **网络层加固**：补齐了对运营商级 NAT、云主机元数据地址和 IPv6 过渡地址的拒绝规则；每个请求都带总时限，慢速滴水式的上游不会一直占用连接。
- **解析修正**：XML 源里带 `&` 的标题、简介和播放地址不再被截断；GBK / Big5 编码的源与网页现在能正确读出。
- **删除与修复更可靠**：删除源、补全相对地址这些操作，要么完整生效，要么明确报错，不再出现「删了又回来」。
- **播放**：「接着看」现在会真的跳到上次位置；播放失败后「重试」不再卡在转圈。
- **界面**：配置里带注释或尾逗号时，导入对话框的勾选现在会真正生效；筛选面板与导入列表在大配置下更跟手。

## 安装

从下方下载 `Moseek_1.0.0_x64-setup.exe` 运行即可。安装到当前用户目录，不需要管理员权限。

安装包未做代码签名，Windows SmartScreen 会提示「未知发布者」，选择「更多信息 → 仍要运行」即可。

## 系统要求

- Windows 10 1809 或更高版本（x64）
- 首次启动需要联网安装 WebView2 运行时（安装包已内置引导程序）
