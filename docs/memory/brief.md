# Project Brief

拾影 (Shiying / Moseek) 是一个面向 Windows 优先的桌面端影视资源聚合工作台与多源流媒体播放器，Slogan 为「万千影画，一拾即得」。它连接并整合多元化的视听生态：支持透明 TVBox/CatVod 配置导入、普通 CMS/直播源探测分类、影视聚合检索与多线路秒开、HLS 原生硬件加速直播、以及受沙盒保护的安全执行边界。

前端采用 React 19 + Vite + TypeScript + Tailwind CSS v4 + 精致紧凑的「极光黑曜 (Cinematic Obsidian)」黑曜石暗色影院级 UI 设计规范，搭配 Tauri 2 作为桌面壳体与 Rust 高性能媒体/网络/存储层。
